# ТЗ — Nuances CRM

## Контекст

Юридическая CRM для фирмы «Нюансы». 2–3 юриста сейчас, до 10 в перспективе.
Разрабатывается итерационно — по одной фиче.

Бизнес запускается с нуля: исторических данных нет, структура создаётся сразу
правильной (импорт из внешних таблиц не нужен).

---

## Архитектура

Модульный монолит + Telegram-бот и планировщик отдельными сервисами.
Микросервисы избыточны для 2–10 пользователей.

```
┌─────────────────────────────────────────┐
│        Nginx (frontend, :80)             │
└────────────┬────────────────────────────┘
             │
    ┌────────┴─────────┐
    ▼                  ▼
┌──────────┐    ┌──────────────┐
│ Vue 3 SPA│    │ Django API   │◀── scheduler (напоминания, счета)
│ Vuetify  │    │ + Channels   │◀── bot (aiogram 3)
└──────────┘    └──────┬───────┘
                       │
        ┌──────────────┴──────────────┐
        ▼                             ▼
  ┌──────────┐                  ┌──────────┐
  │PostgreSQL│                  │  Redis   │
  │          │                  │(channels)│
  └──────────┘                  └──────────┘
```

Файлы хранятся на диске (том `media_files`); ветка S3/MinIO осталась в коде,
но выключена — на объёмах фирмы она не нужна.

## Стек

| Слой | Технология |
|---|---|
| Frontend | Vue 3 + Vuetify 3 + Pinia |
| Backend | Django 4.2 + DRF + Channels |
| База данных | PostgreSQL 16 |
| Кэш / WS | Redis |
| Файлы | локальный том |
| Telegram | aiogram 3 (отдельный контейнер) |
| PDF | WeasyPrint (pydyf 0.10 — новее ломает) |
| Сервер | Daphne (ASGI) + Nginx |
| Деплой | Docker Compose |
